The probes use ActiveProcessorCount=2 to set a comparable default carrier budget;
that flag is not needed by the implementation. No agent, native export/open,
preview option, private JDK class or third-party runtime dependency is used.

Integration limits: selected owned executor and the core wait hooks are required.
Other waits/unknown queues are not intercepted. Concrete ThreadPoolExecutor hooks,
metrics, source type casts, and serial concurrency guarantees are not preserved.
Native roots retain ordinary platform-pool task context semantics; helped roots
are fresh virtual threads. ScopedValue/private custom-scheduler integration is
outside the proof. Independently spawned producer bodies remain unstructured.

Throughput: root owns all gRPC/load tests; functional/race successes here alone
do not establish 900 requests/s or unmounting of A's raw stack.
